# Дипломная работа: CityBikes

Источник: https://app.simulative.ru/course/34/1364

## Требования

1. Airflow: загрузить JSON сетей и станций в PostgreSQL. Таблицы с личным префиксом, ключи без дублей, связь network_id, сохранение дополнительных полей, NULL для отсутствующих значений и логирование.
2. Spark: соединить таблицы, разобрать JSON с явными типами, привести даты разных форматов, очистить строки, получить companies_count и network_station. Сохранить плоскую витрину в HDFS в личной директории `dm`.
3. Перенести витрину из HDFS в ClickHouse.
4. Создать Metabase-дашборд по витрине: сети, станции, города, способы оплаты, электровелосипеды и доступность.
5. Опубликовать GitHub с описанием, архитектурой и схемой данных. Для сдачи приложить ссылки на DAG, дашборд и README.

## Исходные файлы курса
